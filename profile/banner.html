Paperhive
MINECRAFT SERVER HOST

Many Paper servers.
One JVM.

Run a whole network from one process: every server gets its own class loader, folder and console, shares one host, and talks to the others through the Hive API. A Velocity proxy can live in the hive too.

paperhive.yml 
Version: 1.21.11
Servers:
  - Name: lobby
    Port: 25566
  - Name: survival
    Port: 25567
  - Name: proxy
    Port: 25565
    Software: velocitymc
